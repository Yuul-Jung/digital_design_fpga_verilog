## 학습 안내

이 장은 Verilog 코드를 한 줄도 쓰지 않고, Vivado가 제공하는 **IP(Intellectual Property, 미리 만들어진 회로 블록)** 를 **Block Design** 화면에 배치하고 연결해 LED 점멸 회로를 만듭니다. 이후 SoC(System on Chip) 설계에서 CPU·버스·주변장치를 조립하는 방식의 첫걸음입니다.

| 항목 | 내용 |
|---|---|
| 설계 방식 | Vivado IP Integrator · Block Design |
| 보드 | Basys3 (`xc7a35tcpg236-1`) |
| 사용 IP | Clocking Wizard, Binary Counter, Slice |
| 입력 | Basys3 100MHz 클록 |
| 출력 | LED0 |
| 완료 기준 | LED0이 약 1.5Hz로 천천히 점멸 |

**회로 구조**

![clk에서 Clocking Wizard, Binary Counter, Slice를 거쳐 led로 가는 Block Design](images/ch06/svg_ip_block_design.svg)
*그림 6-1. IP 기반 LED 점멸 Block Design 구성*

| IP | 역할 |
|---|---|
| Clocking Wizard | 클록을 생성하거나 정리 |
| Binary Counter | 클록마다 값이 증가 |
| Slice | 여러 비트 중 필요한 비트만 선택 |

**전체 절차**

1. 프로젝트 생성 → 2. Block Design 생성 → 3. IP 추가 → 4. IP 설정 → 5. 외부 포트 생성 → 6. 신호 연결 → 7. Validate Design → 8. Output Products·HDL Wrapper 생성 → 9. XDC 작성 → 10. Synthesis → 11. Implementation → 12. Bitstream → 13. Program → 14. LED 확인

## 프로젝트와 Block Design 생성

**Step 1 · 프로젝트 생성** — Vivado에서 **Create Project**를 선택합니다.

| 항목 | 설정 |
|---|---|
| Project name | `ip_led_counter_prj` |
| Project type | RTL Project |
| Sources | Do not specify sources at this time (선택 가능) |
| Board | Digilent Basys3 |
| Part | `xc7a35tcpg236-1` |

Basys3 보드 파일이 목록에 없으면 Parts 탭에서 `xc7a35tcpg236-1`을 직접 고릅니다.

**Step 2 · Block Design 생성**

```text
Flow Navigator → IP Integrator → Create Block Design
```

이름은 `ip_led_counter_bd`로 입력합니다.

**Step 3 · IP 추가** — Block Design 화면의 **+** 버튼으로 다음 순서대로 추가합니다.

| 순서 | IP | 역할 |
|---|---|---|
| 1 | Clocking Wizard | 클록 입력 및 출력 생성 |
| 2 | Binary Counter | 클록마다 숫자 증가 |
| 3 | Slice | 카운터의 특정 비트 선택 |

## IP 설정

신호 연결은 모든 설정을 마친 뒤 한꺼번에 하므로, 이 단계에서는 각 IP를 더블클릭해 **설정만** 맞춥니다.

**Step 4 · 클록 입력 주파수** — Clocking Wizard의 `clk_in1`(또는 외부 클록 포트)에서 **Customize Pin**을 열고 Frequency를 지정합니다.

| 항목 | 값 |
|---|---|
| Frequency | `100000000` |
| 단위 | Hz (100MHz) |

> **주의:** 단위가 Hz이므로 `100`이 아니라 반드시 `100000000`을 입력합니다.

**Step 5 · Clocking Wizard**

| 항목 | 값 |
|---|---|
| Input Clock | 100MHz |
| Output Clock | 100MHz |
| Reset | 사용하지 않음 또는 기본값 |
| Locked | 사용하지 않아도 됨 |

**Step 6 · Binary Counter**

| 항목 | 값 |
|---|---|
| Output Width | 26 |
| Count Mode | Up |
| Clock Enable | 사용하지 않음 또는 기본값 |
| Reset | 사용하지 않음 또는 기본값 |

100MHz에서는 낮은 비트가 너무 빨리 바뀌어 눈으로 볼 수 없으므로 26비트 카운터를 씁니다.

**Step 7 · Slice** — 카운터의 25번 비트만 꺼내 LED로 보냅니다(`counter[25] → led`).

| 항목 | 값 |
|---|---|
| DIN Width | 26 |
| DIN From | 25 |
| DIN Down To | 25 |
| DOUT Width | 1 |

## 카운터 비트와 분주

이진 카운터의 각 비트는 클록을 2의 거듭제곱으로 나눈 신호입니다. 즉 **카운터 비트 선택 = 분주 회로**입니다.

```text
counter[n] 출력 주파수 = 입력 클록 / 2^(n+1)

counter[25] = 100MHz / 2^26 = 100,000,000 / 67,108,864 ≈ 1.49Hz
```

| 선택 비트 | 분주비 | 출력 주파수 |
|---|---|---|
| `counter[0]` | 2^1 | 50MHz |
| `counter[1]` | 2^2 | 25MHz |
| `counter[10]` | 2^11 | 약 48.8kHz |
| `counter[20]` | 2^21 | 약 47.7Hz |
| `counter[25]` | 2^26 | 약 1.49Hz |

같은 원리를 Verilog로 쓰면 다음과 같습니다. 4장에서 배운 Tick 방식과 달리 비트 출력은 Duty 50%의 점멸 신호가 됩니다.

```verilog
reg [25:0] counter;

always @(posedge clk)
    counter <= counter + 1'b1;

assign led = counter[25];   // 약 1.49Hz 점멸
```

## 외부 포트와 신호 연결

**Step 8 · 외부 포트 생성** — 보드 핀과 연결할 포트를 만듭니다.

| 포트 | 방향 | 만드는 방법 | 연결 대상 |
|---|---|---|---|
| `clk` | input | Clocking Wizard `clk_in1` 우클릭 → **Make External** → 이름 `clk` | Basys3 100MHz 클록 |
| `led` | output | Slice `Dout` 우클릭 → **Make External** → 이름 `led` | Basys3 LED0 |

**Step 9 · IP 신호 연결**

```text
clk → Clocking Wizard clk_in1
      Clocking Wizard clk_out1 → Binary Counter CLK
                                 Binary Counter Q → Slice Din
                                                    Slice Dout → led
```

| 연결 | 의미 |
|---|---|
| `clk` → `clk_in1` | 외부 클록 입력 |
| `clk_out1` → Counter `CLK` | 카운터 구동 클록 |
| Counter `Q` → Slice `Din` | 카운터 값 전달 |
| Slice `Dout` → `led` | 선택 비트를 LED로 출력 |

**Step 10 · Validate Design** — Block Design 상단의 체크 아이콘 또는 **Tools → Validate Design**을 실행해 `Validation successful`을 확인합니다. Validate는 **연결 구조 검사**일 뿐 기능 검증은 아닙니다.

## Wrapper와 XDC

**Step 11 · Output Products 생성** — Sources 창에서 `ip_led_counter_bd.bd` 우클릭 → **Generate Output Products** → 기본값으로 진행합니다.

**Step 12 · HDL Wrapper 생성** — **HDL Wrapper**는 내부 Block Design은 그대로 두고 바깥에서 핀과 신호를 연결해 주는 **최상위 포장 모듈**입니다.

1. `ip_led_counter_bd.bd` 우클릭 → **Create HDL Wrapper**
2. **Let Vivado manage wrapper and auto-update** 선택
3. 생성 파일 `ip_led_counter_bd_wrapper.v`가 최상위 모듈이 됨

**Step 13 · XDC 작성** — Add Sources → Add or create constraints → Create File

파일명: `basys3_ip_led_counter.xdc`

```tcl
# Basys3 100MHz Clock
set_property PACKAGE_PIN W5 [get_ports clk]
set_property IOSTANDARD LVCMOS33 [get_ports clk]
create_clock -add -name sys_clk_pin -period 10.00 -waveform {0 5} [get_ports clk]

# Basys3 LED0
set_property PACKAGE_PIN U16 [get_ports led]
set_property IOSTANDARD LVCMOS33 [get_ports led]
```

XDC의 포트 이름은 **Wrapper의 포트 이름과 반드시 같아야** 합니다.

| 너무 느림 | Slice 비트를 더 낮은 비트로 |

## 시뮬레이션 테스트

보드 테스트 전에 시뮬레이션으로 기본 동작을 확인할 수 있습니다. `counter[25]`는 시뮬레이션에서 변화가 매우 느리므로 시뮬레이션용으로는 낮은 비트를 고릅니다.

| 구분 | 권장 비트 |
|---|---|
| 보드 테스트 | `counter[25]` |
| 시뮬레이션 | `counter[5]` 또는 `counter[10]` |

Wrapper 포트 이름이 `clk`, `led`라고 가정합니다.

파일명: `tb_ip_led_counter_bd_wrapper.v`

```verilog
`timescale 1ns / 1ps
module tb_ip_led_counter_bd_wrapper;

    reg  clk;
    wire led;

    ip_led_counter_bd_wrapper dut (
        .clk(clk),
        .led(led)
    );

    // 100MHz Clock 생성
    initial begin
        clk = 1'b0;
        forever #5 clk = ~clk;
    end

    // 시뮬레이션 종료
    initial begin
        #1000000;   // 1ms
        $finish;
    end

endmodule
```

**실행:** Add Sources → Add or create simulation sources → `tb_ip_led_counter_bd_wrapper.v` 추가 → Run Simulation → Run Behavioral Simulation

| 신호 | 확인 내용 |
|---|---|
| `clk` | 10ns 주기로 반복 |
| `led` | 시간이 지나면서 값 변화 |

변화가 보이지 않으면 시뮬레이션 시간을 늘리거나 Slice 비트를 낮춥니다. Clocking Wizard는 시작 직후 클록이 안정(Locked)될 때까지 잠시 출력이 없을 수 있습니다.

## 오류 점검과 체크리스트

| 문제 | 확인 사항 |
|---|---|
| HDL Wrapper 없음 | Create HDL Wrapper 실행 |
| Synthesis 오류 | IP Output Products 생성 여부 |
| Bitstream 오류 | XDC의 `PACKAGE_PIN`, `IOSTANDARD` |
| LED 동작 없음 | `clk`·`led` 포트 이름, `clk_out1` ↔ Counter `CLK`, Counter `Q` ↔ Slice `Din` 연결 |
| LED 변화 안 보임 | Slice 비트 위치 |
| 보드 인식 안 됨 | USB 케이블, 전원, Hardware Manager |

## 정리와 점검

| 개념 | 핵심 |
|---|---|
| IP | 이미 만들어진 회로 블록 |
| Block Design | IP를 배치하고 연결하는 설계 화면 |
| Clocking Wizard | 클록 생성·정리 |
| Binary Counter | 클록마다 값 증가 |
| Slice | 필요한 비트만 선택 |
| HDL Wrapper | Block Design을 최상위 Verilog 모듈로 포장 |
| XDC | FPGA 포트를 Basys3 실제 핀에 연결 |

**IP 설계 핵심 흐름**

```text
IP 추가 → IP 설정 → 외부 포트 생성 → 신호 연결 → HDL Wrapper 생성
→ XDC 작성 → Bitstream 생성 → 보드 테스트
```
