## 학습 안내

지금까지의 조합회로는 현재 입력만 보고 출력을 정했습니다. 그러나 디지털 시계는 현재 시간을, UART는 전송 중인 비트 위치를, 자판기는 투입 금액을 **기억**해야 합니다. 이 장은 기억 기능을 가진 **순차회로(Sequential Logic)** 를 래치에서 시작해 플립플롭, 레지스터, 시프트 레지스터, 카운터, 4자리 FND 표시까지 단계적으로 쌓아 올립니다.

| 구분 | 조합회로 | 순차회로 |
|---|---|---|
| 출력 | 현재 입력의 함수 | 현재 입력 + **이전 상태** |
| 기억 기능 | 없음 | 있음 (State) |
| 클록 | 사용하지 않음 | 사용 |
| 대표 회로 | AND, MUX, Decoder, Adder | Latch, Flip-Flop, Register, Counter |

| 절 | 실습 | 핵심 |
|---|---|---|
| 래치 | 조합회로와 SR 래치 비교, 의도치 않은 래치 | Level Sensitive의 위험 |
| 플립플롭 | D-FF, 리셋, 래치와 비교 | Edge Sensitive, `<=` |
| 레지스터 | 8비트, Enable, Load, Reset | 여러 비트 동시 저장 |
| 시프트 레지스터 | SISO, 좌우 이동, SIPO, PISO, 범용(74194) | 저장 + 이동 |
| 카운터 1 | Tick, 1Hz, Mod-10, 1자리 FND | Tick은 클록이 아닌 Enable |
| 카운터 2 | 2·4자리 BCD, FND 다중화, 4자리 FND | 자리 올림과 스캔 표시 |

**공통 설계 기준**

| 항목 | 기준 |
|---|---|
| 순차회로 | `always @(posedge clk)` + `<=` |
| 조합회로 | `always @(*)` 또는 `assign` + `=` |
| 테스트벤치 | `tb_` 접두어, `` `timescale 1ns / 1ps `` |
| 내부 생성 신호 | Tick·Blink를 **클록으로 쓰지 않음** |

## 순차회로와 래치

**SR 래치(SR Latch)** 는 가장 기본적인 기억 소자입니다. 출력이 다시 내부 입력으로 연결되는 **피드백(Feedback)** 구조 덕분에 입력이 사라져도 값을 유지합니다.

| S (Set) | R (Reset) | Q |
|:-:|:-:|---|
| 0 | 0 | 이전 상태 유지 |
| 1 | 0 | 1 저장 |
| 0 | 1 | 0 저장 |
| 1 | 1 | 금지 상태 |

![NOR 게이트 두 개로 만든 SR 래치와 기호](images/ch04/sr_latch.png)
*그림 4-1. SR 래치 회로와 기호 (출처: 원 강의자료 인용 교재 도판)*


래치는 Enable이 1인 **동안** 계속 입력을 반영하는 **Level Sensitive** 회로입니다. SRAM 셀 내부, 비동기 회로, 일부 디바운스·ASIC 회로에서는 지금도 쓰이지만 FPGA RTL 설계에서는 거의 쓰지 않습니다.

| 래치의 문제 | 내용 |
|---|---|
| Level Sensitive | Enable 동안 입력이 흔들리면 출력도 흔들림 |
| 글리치(Glitch) | 0 → 순간 1 → 0 같은 짧은 잡음도 저장될 수 있음 |
| 타이밍 | 입력 변경·Enable 종료·지연 시간이 모두 중요해져 예측이 어려움 |
| Inferred Latch | 잘못 쓴 Verilog에서 합성기가 의도치 않은 래치를 만듦 |

**실습 1 · 조합회로와 SR 래치 비교**

파일명: `compare_memory.v`

```verilog
module compare_memory(
    input      a,   // 조합회로 입력
    input      s,   // Set 입력
    input      r,   // Reset 입력
    output     y,   // 조합회로 출력
    output reg q    // Latch 출력
);

    assign y = a;   // 조합회로: 입력을 바로 출력

    always @(*) begin
        if (s)
            q = 1'b1;   // Set: 1 저장
        else if (r)
            q = 1'b0;   // Reset: 0 저장
        // s=0, r=0이면 이전 q 유지
    end

endmodule
```

파일명: `tb_compare_memory.v`

```verilog
`timescale 1ns / 1ps
module tb_compare_memory;

    reg  a, s, r;
    wire y, q;

    compare_memory dut(.a(a), .s(s), .r(r), .y(y), .q(q));

    initial begin
        a = 1'b0; s = 1'b0; r = 1'b0; #10;
        a = 1'b1; #10;               // 조합회로 출력 변화
        a = 1'b0; #10;
        s = 1'b1; r = 1'b0; #10;     // q = 1 저장
        s = 1'b0; r = 1'b0; #10;     // q = 1 유지
        s = 1'b0; r = 1'b1; #10;     // q = 0 저장
        s = 1'b0; r = 1'b0; #10;     // q = 0 유지
        $finish;
    end

endmodule
```

## D 플립플롭

**플립플롭(Flip-Flop)** 은 클록의 **특정 순간(Edge)** 에만 입력을 저장하는 **Edge Sensitive** 소자입니다. 모든 상태가 같은 기준 시점에 동시에 바뀌므로 동작을 예측하기 쉽습니다. 실무에서는 D 플립플롭을 가장 많이 쓰고 JK·T 플립플롭은 거의 쓰지 않습니다.

| CLK | D | Q |
|---|:-:|---|
| 상승 에지 없음 | 0 또는 1 | 이전 상태 유지 |
| 상승 에지(0→1) | 0 | 0 저장 |
| 상승 에지(0→1) | 1 | 1 저장 |

| 항목 | Latch | Flip-Flop |
|---|---|---|
| 동작 기준 | Enable Level | Clock Edge |
| 입력 반영 | Enable 동안 계속 | 에지 순간만 |
| 글리치 영향 | 큼 | 작음 |
| FPGA RTL | 가급적 피함 | 기본 저장소 |
| 대표 코드 | `always @(*)` | `always @(posedge clk)` |

**Blocking(`=`)과 Non-blocking(`<=`)**

| 구분 | 기호 | 주 사용 | 의미 |
|---|---|---|---|
| Blocking | `=` | 조합논리 | 즉시 대입 |
| Non-blocking | `<=` | 순차논리 | 같은 에지에서 동시 갱신 |

플립플롭은 여러 신호가 같은 클록 에지에서 동시에 갱신되는 회로이므로 `q <= d;`로 씁니다. `q = d;`도 문법적으로는 동작할 수 있지만 순차회로에는 권장하지 않습니다.

**리셋(Reset)** — 전원을 켤 때 Q가 원하는 값으로 시작한다는 보장이 없으므로 회로의 출발점을 정하는 신호가 필요합니다.

| 구분 | 동기 리셋 | 비동기 리셋 |
|---|---|---|
| 동작 시점 | 클록 에지에서 반영 | 리셋 입력 즉시 |
| 클록 | 필요 | 불필요 |
| 장점 | 타이밍 관리·파형 분석이 쉬움 | 즉시 초기화 |
| 주의 | 클록이 멈추면 리셋 불가 | 해제 시점 주의 |

```verilog
// 동기 리셋
always @(posedge clk) begin
    if (rst)
        q <= 1'b0;
    else
        q <= d;
end

// 비동기 리셋
always @(posedge clk or posedge rst) begin
    if (rst)
        q <= 1'b0;
    else
        q <= d;
end
```

## 레지스터

**레지스터(Register)** 는 플립플롭 여러 개를 묶어 여러 비트를 동시에 저장하는 회로입니다. 8비트 레지스터는 플립플롭 8개로 이루어집니다. CPU 명령어, UART 송수신 데이터, 카운터 현재값, FSM 상태가 모두 레지스터에 저장되며, FPGA는 사실상 **레지스터 + 조합논리**로 동작합니다.

```text
D[7:0] → Register → Q[7:0]
            ↑
           CLK   (상승 에지에서 저장, 나머지 구간은 유지)
```

| 기능 | 역할 |
|---|---|
| Enable | 저장 허용 |
| Load | 저장 명령 (MUX로 D/Q 선택) |
| Reset/Clear | 초기화 |
| Hold | 이전 상태 유지 |

**실습 1 · 기본 8비트 레지스터**

파일명: `register8.v`


## 시프트 레지스터 기초

**시프트 레지스터(Shift Register)** 는 데이터를 저장하면서 클록마다 한 비트씩 **이동**시킵니다. UART·SPI 직렬 통신, CPU 시프트 연산, 영상 처리의 픽셀 이동, DSP 지연선(Delay Line)의 기본 구조입니다.

![din에서 q[0]~q[3]를 거쳐 serial_out으로 이동하는 시프트 레지스터](images/ch04/svg_siso_shift.svg)
*그림 4-34. `shift_register_siso` 구조 — `q <= {q[2:0], din};`, `serial_out = q[3]`*

| 종류 | 의미 |
|---|---|
| SISO | Serial In, Serial Out |
| SIPO | Serial In, Parallel Out (UART 수신) |
| PISO | Parallel In, Serial Out (UART 송신) |
| PIPO | Parallel In, Parallel Out |

**결합 연산자 `{ }`로 이동 표현** — 왼쪽이 상위 비트입니다(`{1'b1, 1'b0}` = `2'b10`).

| 문법 | 의미 | 이동 |
|---|---|---|
| `q <= {q[2:0], din};` | Shift Left | q[2]→q[3], q[1]→q[2], q[0]→q[1], din→q[0] |
| `q <= {din, q[3:1]};` | Shift Right | din→q[3], q[3]→q[2], q[2]→q[1], q[1]→q[0] |
| `{4{1'b0}}` | 0을 4개 반복 | `4'b0000` |

> 리셋이 없는 시프트 레지스터는 시뮬레이션 초기에 `q`가 `x`로 보일 수 있습니다. 첫 이동 이후의 흐름을 관찰하고, 초기값이 꼭 필요하면 리셋을 추가합니다.

## PISO와 범용 시프트 레지스터

**실습 4 · PISO (병렬 → 직렬)** — `load`로 병렬 데이터를 넣고, 이후 오른쪽으로 밀면서 `q[0]`을 내보냅니다. 출력 순서가 **LSB First**라는 점이 매우 중요합니다.

파일명: `shift_register_piso.v`

```verilog
module shift_register_piso(
    input            clk,         // 기준 Clock
    input            load,        // 병렬 Load
    input      [3:0] pdata,       // 병렬 입력
```

`4'b1011`을 넣으면 `serial_out`은 **1 → 1 → 0 → 1** 순서로 나옵니다. 병렬 데이터가 시간축의 직렬 데이터로 바뀐 것입니다.

**실습 5 · 범용 시프트 레지스터 (74194 기반)** — SISO·SIPO·PISO·PIPO를 하나의 회로에서 모드로 고릅니다. 74194는 범용 시프트 레지스터의 대표 TTL IC입니다.

| mode | 동작 | 의미 |
|---|---|---|
| 00 | Hold | 현재 값 유지 |
| 01 | Serial In Shift | 직렬 입력을 넣으며 오른쪽 이동 |
| 10 | Serial Out Shift | `q[0]`을 내보내며 오른쪽 이동 |
| 11 | Parallel Load | 병렬 데이터 저장 |

파일명: `universal_shift_register.v`

```verilog
module universal_shift_register(
    input            clk,         // 기준 Clock
    input            reset,       // 동기 Reset
    input      [1:0] mode,        // 동작 모드
    input            serial_in,   // 직렬 입력
    input      [3:0] pdata,       // 병렬 입력
    output           serial_out,  // 직렬 출력
    output reg [3:0] q            // 병렬 출력
);

    assign serial_out = q[0];     // LSB First 출력

    always @(posedge clk) begin
        if (reset)
            q <= 4'b0000;                                // 초기화
        else begin
            case (mode)
                2'b00:   q <= q;                         // Hold
                2'b01:   q <= {serial_in, q[3:1]};       // Serial In Shift
                2'b10:   q <= {1'b0, q[3:1]};            // Serial Out Shift
                2'b11:   q <= pdata;                     // Parallel Load
                default: q <= q;
            endcase
        end
    end

endmodule
```

파일명: `tb_universal_shift_register.v`

## Basys3 범용 시프트 레지스터 실습

버튼을 **수동 클록**으로 써서 한 단계씩 시프트 동작을 눈으로 확인합니다. 포트 이름은 Basys3 Master XDC를 그대로 쓸 수 있도록 맞췄습니다.

| 포트 | 장치 | 역할 |
|---|---|---|
| `btnC` | 가운데 버튼 | 수동 클록 |
| `btnU` | 위 버튼 | Parallel Load |
| `sw[1:0]` | SW0~1 | 모드 선택 |
| `sw[7:4]` | SW4~7 | 병렬 입력 |
| `sw[8]` | SW8 | 직렬 입력 |
| `led[3:0]` | LED0~3 | 병렬 출력 |
| `led[4]` | LED4 | 직렬 출력 |
| `led[15:5]` | LED5~15 | 미사용, 0 |

파일명: `basys3_universal_shift_register.v`

```verilog
module basys3_universal_shift_register(
    input         btnC,   // 수동 Clock
    input         btnU,   // Parallel Load 버튼
    input  [15:0] sw,     // Basys3 Switch
    output [15:0] led     // Basys3 LED
);

    reg  [3:0] q;
    wire [1:0] mode;
    wire       serial_in;
    wire [3:0] pdata;

    assign mode      = sw[1:0];
    assign pdata     = sw[7:4];
    assign serial_in = sw[8];

    assign led[3:0]  = q;       // 병렬 출력
    assign led[4]    = q[0];    // LSB First 직렬 출력
    assign led[15:5] = 11'b0;   // 미사용 LED는 0으로 고정

    always @(posedge btnC) begin
        if (btnU)
            q <= pdata;                                  // 버튼 Load 우선
        else begin
            case (mode)
                2'b00:   q <= q;                         // Hold
                2'b01:   q <= {serial_in, q[3:1]};       // Serial In Shift
                2'b10:   q <= {1'b0, q[3:1]};            // Serial Out Shift
                2'b11:   q <= pdata;                     // Parallel Load
                default: q <= q;
            endcase
        end
    end

endmodule
```

파일명: `tb_basys3_universal_shift_register.v`

```verilog
`timescale 1ns / 1ps
module tb_basys3_universal_shift_register;

    reg         btnC, btnU;
    reg  [15:0] sw;
    wire [15:0] led;

    basys3_universal_shift_register dut(.btnC(btnC), .btnU(btnU), .sw(sw), .led(led));

    // 버튼 한 번 누름 = 상승 에지 1회
    task push_clock;
        begin
            btnC = 1'b0; #5;
            btnC = 1'b1; #5;
            btnC = 1'b0; #5;
        end
    endtask

    initial begin
        btnC = 1'b0; btnU = 1'b0; sw = 16'b0; #10;

        sw[7:4] = 4'b1011;              // 병렬 데이터 설정
        btnU = 1'b1; push_clock;        // Load
        btnU = 1'b0;

        sw[1:0] = 2'b00; push_clock;    // Hold

        sw[1:0] = 2'b10;                // PISO: led[4] = 1,1,0,1
        push_clock; push_clock; push_clock; push_clock;

        sw[1:0] = 2'b01;                // SIPO
        sw[8] = 1'b1; push_clock;
        sw[8] = 1'b0; push_clock;
        sw[8] = 1'b1; push_clock;
        sw[8] = 1'b1; push_clock;

        sw[7:4] = 4'b0101;              // PIPO
        sw[1:0] = 2'b11; push_clock;
        #20;
        $finish;
    end

endmodule
```

**보드 실습 순서**

1. `sw[7:4] = 1011`로 병렬 데이터 설정
2. **btnU를 누른 채 btnC를 1회** → `led[3:0] = 1011` (btnU를 계속 누르고 있으면 매 클록 Load만 수행되어 이동하지 않습니다)
3. PISO: `sw[1:0] = 10`, btnC를 누를 때마다 `led[4]`에 **1 → 1 → 0 → 1**
4. SIPO: `sw[1:0] = 01`, `sw[8]`을 바꾸며 btnC → `led[3:0]`에 누적
5. PIPO: `sw[1:0] = 11`, btnC 1회 → `sw[7:4]` 값이 그대로 저장

**XDC 참고:** `btnC`(U18)는 클록 전용 핀이 아니어서 구현 단계에서 클록 배선 오류가 날 수 있습니다. 이때는 XDC에 다음 줄을 추가합니다.

```tcl
set_property CLOCK_DEDICATED_ROUTE FALSE [get_nets btnC_IBUF]
```

> 이 실습은 동작 이해를 위해 버튼을 직접 클록으로 씁니다. 실제 설계에서는 버튼 **디바운스(Debounce)** 와 **동기화기(Synchronizer)** 를 거쳐 시스템 클록 기반으로 처리합니다. 이 구조는 이후 UART 학습의 기초가 됩니다.

## 카운터 1 Tick과 1Hz 신호

카운터 실습은 **Tick**과 **Blink**를 구분하는 데서 출발합니다.

| 신호 | 의미 | 용도 |
|---|---|---|
| `tick_0p5s` | 0.5초마다 **1클록 동안만** 1 | 기준 Tick |
| `tick_1hz` | 1초마다 1클록 동안만 1 | 카운터 증가 **Enable** |
| `blink_1hz` | 0.5초마다 반전, 1Hz·Duty 50% | LED·DP 점멸 |

> **Tick은 클록이 아닙니다.** 1클록 폭의 Enable 신호입니다. 모든 레지스터는 시스템 클록 하나(`posedge clk`)로 동작하고, Tick은 "이번 클록에 움직여도 된다"는 허가로만 씁니다.

**Step 1-1 · Tick 생성** — 클록을 세어 5클록마다 1클록 폭의 Tick을 냅니다.

```text
clk → Counter → Compare → tick
```

파일명: `clock_divider_tick.v`

```verilog
module clock_divider_tick(
    input      clk,    // 기준 Clock 입력
    input      reset,  // 동기 Reset 입력
    output reg tick    // 5 Clock마다 1 Clock 동안 1
);

    reg [2:0] div_count;   // 0~4까지 세는 Counter

    always @(posedge clk) begin
        if (reset) begin
            div_count <= 3'd0;
            tick      <= 1'b0;
        end
        else begin
            if (div_count == 3'd4) begin
                div_count <= 3'd0;              // 5번째 Clock에서 0으로 복귀
                tick      <= 1'b1;              // 1 Clock 동안 Tick 발생
            end
            else begin
                div_count <= div_count + 1'b1;  // Clock 개수 증가
                tick      <= 1'b0;
            end
        end
    end

endmodule
```

파일명: `tb_clock_divider_tick.v`

```verilog
`timescale 1ns / 1ps
module tb_clock_divider_tick;

    reg  clk, reset;
    wire tick;

    clock_divider_tick dut(.clk(clk), .reset(reset), .tick(tick));

    initial begin
        clk = 1'b0;
        forever #5 clk = ~clk;   // 10ns 주기 Clock
    end

    initial begin
        reset = 1'b1; #20;
        reset = 1'b0; #200;      // Tick 반복 발생 확인
        $finish;
    end

endmodule
```

`div_count`가 0→1→2→3→4→0을 반복하고, `tick`이 5클록마다 1클록 동안 1이 되는지 확인합니다.

**Step 1-2 · 0.5초 Tick과 1Hz 신호** — 100MHz(주기 10ns)에서 0.5초는 50,000,000클록이므로 비교값은 **49,999,999**입니다.

```text
100MHz Clock → 50,000,000개 Count → tick_0p5s 발생 → blink_1hz 반전
                                   → 0.5초 Tick 2번 Count → tick_1hz 발생
```

파일명: `clock_tick_and_blink.v`

```verilog
module clock_tick_and_blink(
    input      clk,        // Basys3 100MHz Clock
    input      reset,      // 동기 Reset
    output reg tick_0p5s,  // 0.5초마다 1 Clock 동안 1
    output reg tick_1hz,   // 1초마다 1 Clock 동안 1
    output reg blink_1hz   // 1Hz Duty 50% 점멸 신호
);

    reg [25:0] div_count;  // 0.5초 생성을 위한 26비트 Counter
    reg        half_count; // 0.5초 Tick 발생 횟수

    always @(posedge clk) begin
        if (reset) begin
            div_count  <= 26'd0;
            half_count <= 1'b0;
            tick_0p5s  <= 1'b0;
            tick_1hz   <= 1'b0;
            blink_1hz  <= 1'b0;
        end
        else begin
            tick_0p5s <= 1'b0;          // 기본값은 Tick 없음
            tick_1hz  <= 1'b0;

            if (div_count == 26'd49_999_999) begin
                div_count <= 26'd0;     // 50,000,000 Clock 도달
                tick_0p5s <= 1'b1;      // 0.5초 Tick
                blink_1hz <= ~blink_1hz;// 0.5초마다 반전

                if (half_count == 1'b1) begin
                    half_count <= 1'b0; // 0.5초 두 번 도달
                    tick_1hz   <= 1'b1; // 1초 Tick
                end
                else begin
                    half_count <= 1'b1; // 첫 번째 0.5초 기록
                end
            end
            else begin
                div_count <= div_count + 1'b1;
            end
        end
    end

endmodule
```

파일명: `tb_clock_tick_and_blink.v`

```verilog
`timescale 1ns / 1ps

```

1.2초 시뮬레이션은 1억 2천만 클록이라 시간이 오래 걸립니다. 빠르게 확인하려면 비교값을 작게 바꾼 사본으로 먼저 구조를 검증합니다.

**연결 방법과 금지 구조**

## 카운터 1 Mod-10과 1자리 FND

**Step 1-3 · 1자리 Up 카운터** — `tick`이 1인 클록에서만 증가하고 0~9를 반복합니다.

파일명: `counter_1digit.v`

```verilog
module counter_1digit(
    input            clk,    // 기준 Clock 입력
    input            reset,  // 동기 Reset 입력
    input            tick,   // Count 증가 Enable
    output reg [3:0] count   // 0~9 Counter 값
);

    always @(posedge clk) begin
        if (reset) begin
            count <= 4'd0;
        end
        else begin
            if (tick) begin                 // Tick이 1일 때만 증가
                if (count == 4'd9)
                    count <= 4'd0;          // 9 다음은 0
                else
                    count <= count + 1'b1;
            end
        end
    end

endmodule
```

파일명: `tb_counter_1digit.v`

```verilog
`timescale 1ns / 1ps
```

**Step 1-4 · Reset + Enable 카운터**

| reset | enable | tick | count |
|:-:|:-:|:-:|---|
| 1 | X | X | 0으로 초기화 |
| 0 | 0 | X | 유지 |
| 0 | 1 | 0 | 유지 |
| 0 | 1 | 1 | 1 증가 |

파일명: `counter_reset_enable.v`

```verilog

        end

        end
    end
```

**Step 1-5 · Mod-10 BCD 카운터** — 9에서 0으로 돌아갈 때 다음 자리를 올리는 **carry**를 1클록 동안 냅니다.

파일명: `mod10_bcd_counter.v`

```verilog
module mod10_bcd_counter(
    input            clk,     // 기준 Clock 입력
    input            reset,   // 동기 Reset 입력
    input            enable,  // Count 동작 허용 신호
    input            tick,    // Count 증가 기준 Tick
    output reg [3:0] bcd,     // 0~9 BCD 값
    output reg       carry    // 9에서 0으로 갈 때 1
);

    always @(posedge clk) begin
        if (reset) begin
            bcd   <= 4'd0;
            carry <= 1'b0;
        end
        else begin
            carry <= 1'b0;                  // Carry 기본값은 0
            if (enable && tick) begin
                if (bcd == 4'd9) begin
                    bcd   <= 4'd0;          // 9 다음은 0
                    carry <= 1'b1;          // 다음 자리 증가용 Carry
                end
                else begin
                    bcd <= bcd + 1'b1;
                end
            end
        end
    end

endmodule
```

**Step 1-6 · Basys3 1자리 FND 카운터 종합** — 1초마다 숫자가 올라가고 DP가 1Hz로 깜빡입니다.

| 포트 | 역할 |
|---|---|
| `clk` | 100MHz 클록 |
| `btnU` | Reset |
| `sw[0]` | Enable |
| `led[3:0]` | 현재 카운트(2진수) |
| `led[15]` | `blink_1hz` 확인 |
| `seg[6:0]`, `an[3:0]`, `dp` | FND |

파일명: `basys3_step1_fnd_counter.v`

```verilog
module basys3_step1_fnd_counter(
    input             clk,    // Basys3 100MHz Clock
    input             btnU,   // Reset 버튼
    input      [15:0] sw,     // sw[0]: Counter Enable
    output     [15:0] led,    // led[3:0]: Count, led[15]: blink 확인
    output reg [6:0]  seg,    // FND Segment 출력
    output reg [3:0]  an,     // FND Digit 선택
    output            dp      // Decimal Point 출력
);

    reg [25:0] div_count;   // 0.5초 Tick 생성 Counter
    reg        half_count;  // 0.5초 Tick 2회 확인용
    reg        tick_0p5s;   // 0.5초마다 1 Clock 동안 1
    reg        tick_1hz;    // 1초마다 1 Clock 동안 1
    reg        blink_1hz;   // 1Hz Duty 50% 점멸 신호
    reg  [3:0] count;       // FND에 표시할 0~9 값

    assign dp        = ~blink_1hz;  // Active-Low DP 점멸
    assign led[3:0]  = count;       // 현재 Count 표시
    assign led[14:4] = 11'd0;       // 미사용 LED
    assign led[15]   = blink_1hz;   // 1Hz 점멸 확인

    // 0.5초 Tick / 1Hz Tick / 1Hz Blink 생성
    always @(posedge clk) begin
        if (btnU) begin
            div_count  <= 26'd0;
            half_count <= 1'b0;
            tick_0p5s  <= 1'b0;
            tick_1hz   <= 1'b0;
            blink_1hz  <= 1'b0;
        end
        else begin
            tick_0p5s <= 1'b0;
            tick_1hz  <= 1'b0;

            if (div_count == 26'd49_999_999) begin
                div_count <= 26'd0;
                tick_0p5s <= 1'b1;
                blink_1hz <= ~blink_1hz;

                if (half_count == 1'b1) begin
                    half_count <= 1'b0;
                    tick_1hz   <= 1'b1;
                end
                else begin
                    half_count <= 1'b1;
                end
            end
            else begin
                div_count <= div_count + 1'b1;
            end
        end
    end

    // 0~9 Counter: sw[0] && tick_1hz 조건에서 증가
    always @(posedge clk) begin
        if (btnU) begin
            count <= 4'd0;
        end
        else begin
            if (sw[0] && tick_1hz) begin
                if (count == 4'd9)
                    count <= 4'd0;
                else
                    count <= count + 1'b1;
            end
        end
    end

    // 1자리 FND 디코더
    always @(*) begin
        an = 4'b1110;   // 오른쪽 1자리만 선택
        case (count)
            4'd0:    seg = 7'b1000000;
            4'd1:    seg = 7'b1111001;
            4'd2:    seg = 7'b0100100;
            4'd3:    seg = 7'b0110000;
            4'd4:    seg = 7'b0011001;
            4'd5:    seg = 7'b0010010;
            4'd6:    seg = 7'b0000010;
            4'd7:    seg = 7'b1111000;
            4'd8:    seg = 7'b0000000;
            4'd9:    seg = 7'b0010000;
            default: seg = 7'b1111111;   // 예외값은 끔
        endcase
    end

endmodule
```

## 카운터 2 다자리 BCD 카운터

Step 2에서는 0.1초 단위로 빠르게 증가하는 4자리 카운터를 만듭니다.

| 신호 | 의미 | 용도 |
|---|---|---|
| `tick_0p05s` | 0.05초마다 1클록 동안 1 | 내부 기준 Tick |
| `tick_0p1s` | 0.1초마다 1클록 동안 1 | 카운터 증가 Enable |
| `blink_10hz` | 0.05초마다 반전 | LED 확인용 |
| `blink_5hz` | 0.1초마다 반전 | LED 확인용 |
| `digit_sel` | FND 선택 번호 | FND 스캔 |

0.05초 = 5,000,000클록(비교값 **4,999,999**), 0.1초는 0.05초 Tick 2번입니다. 1클록 폭 Tick은 LED로 볼 수 없으므로 눈 확인에는 Blink 신호를 씁니다. **FND 스캔은 카운터 증가와 별도로 빠르게 순환**합니다.

**Step 2-1 · 2자리 BCD 카운터 (00~99)**

파일명: `bcd_2digit_counter.v`

```verilog
module bcd_2digit_counter(
    input            clk,     // 기준 Clock 입력
    input            reset,   // 동기 Reset 입력
    input            enable,  // Count 동작 허용 신호
    input            tick,    // Count 증가 Enable
    output reg [3:0] digit0,  // 1의 자리 BCD 값
    output reg [3:0] digit1   // 10의 자리 BCD 값
);

    always @(posedge clk) begin
        if (reset) begin
            digit0 <= 4'd0;
            digit1 <= 4'd0;
        end
        else begin
            if (enable && tick) begin
                if (digit0 == 4'd9) begin
                    digit0 <= 4'd0;                 // 9 다음은 0
                    if (digit1 == 4'd9)
                        digit1 <= 4'd0;             // 99 다음은 00
                    else
                        digit1 <= digit1 + 1'b1;    // 10의 자리 증가
                end
                else begin
                    digit0 <= digit0 + 1'b1;        // 1의 자리 증가
                end
            end
        end
    end

endmodule
```

파일명: `tb_bcd_2digit_counter.v`

```verilog
`timescale 1ns / 1ps
module tb_bcd_2digit_counter;

    reg        clk, reset, enable, tick;
    wire [3:0] digit0, digit1;

    bcd_2digit_counter dut(
        .clk(clk), .reset(reset), .enable(enable), .tick(tick),
        .digit0(digit0), .digit1(digit1)
    );

    initial begin
        clk = 1'b0;
        forever #5 clk = ~clk;
    end

    task make_tick;
        begin
            tick = 1'b1; #10;
            tick = 1'b0; #20;
        end
    endtask

    initial begin
        reset = 1'b1; enable = 1'b0; tick = 1'b0; #20;
        reset = 1'b0; enable = 1'b1;
        repeat (105) begin       // 00~99 반복 확인
            make_tick;
        end
        enable = 1'b0;
        make_tick; make_tick;    // 값 유지 확인
        $finish;
    end

endmodule
```

09 다음은 10, 99 다음은 00이 되는지 확인합니다.

**Step 2-2 · 4자리 BCD 카운터 (0000~9999)** — 낮은 자리가 9→0이 될 때 높은 자리가 오르는 구조를 중첩합니다.

파일명: `bcd_4digit_counter.v`

```verilog
module bcd_4digit_counter(
    input            clk,     // 기준 Clock 입력
    input            reset,   // 동기 Reset 입력
    input            enable,  // Count 동작 허용 신호
    input            tick,    // Count 증가 Enable
    output reg [3:0] digit0,  // 1의 자리
    output reg [3:0] digit1,  // 10의 자리
    output reg [3:0] digit2,  // 100의 자리
    output reg [3:0] digit3   // 1000의 자리
);

    always @(posedge clk) begin
        if (reset) begin
            digit0 <= 4'd0;
            digit1 <= 4'd0;
            digit2 <= 4'd0;
            digit3 <= 4'd0;
        end
        else begin
            if (enable && tick) begin
                if (digit0 == 4'd9) begin
                    digit0 <= 4'd0;                         // digit0 Carry
                    if (digit1 == 4'd9) begin
                        digit1 <= 4'd0;                     // digit1 Carry
                        if (digit2 == 4'd9) begin
                            digit2 <= 4'd0;                 // digit2 Carry
                            if (digit3 == 4'd9)
                                digit3 <= 4'd0;             // 9999 다음은 0000
                            else
                                digit3 <= digit3 + 1'b1;
                        end
                        else begin
                            digit2 <= digit2 + 1'b1;
                        end
                    end
                    else begin
                        digit1 <= digit1 + 1'b1;
                    end
                end
                else begin
                    digit0 <= digit0 + 1'b1;
                end
            end
        end
    end

endmodule
```

## 카운터 2 FND 다중화와 4자리 표시

**Step 2-3 · FND 다중화(Multiplexing)** — 네 자리 값 중 `digit_sel`이 가리키는 자리만 세그먼트로 바꾸고, 해당 `an`만 0으로 만듭니다.

파일명: `fnd_multiplexer_4digit.v`

```verilog
module fnd_multiplexer_4digit(
    input      [3:0] digit0,     // 표시할 digit0 값
    input      [3:0] digit1,     // 표시할 digit1 값
    input      [3:0] digit2,     // 표시할 digit2 값
    input      [3:0] digit3,     // 표시할 digit3 값
    input      [1:0] digit_sel,  // 현재 선택된 Digit 번호
    output reg [3:0] an,         // Digit 선택, Active-Low
    output reg [6:0] seg         // Segment 출력, Active-Low
);

    reg [3:0] current_digit;     // 현재 seg로 변환할 값

    // 자리 선택
    always @(*) begin
        case (digit_sel)
            2'd0: begin current_digit = digit0; an = 4'b1110; end
            2'd1: begin current_digit = digit1; an = 4'b1101; end
            2'd2: begin current_digit = digit2; an = 4'b1011; end
            2'd3: begin current_digit = digit3; an = 4'b0111; end
            default: begin current_digit = 4'd0; an = 4'b1111; end
        endcase
    end

    // 세그먼트 디코더
    always @(*) begin
        case (current_digit)
            4'd0:    seg = 7'b1000000;
            4'd1:    seg = 7'b1111001;
            4'd2:    seg = 7'b0100100;
            4'd3:    seg = 7'b0110000;
            4'd4:    seg = 7'b0011001;
            4'd5:    seg = 7'b0010010;
            4'd6:    seg = 7'b0000010;
            4'd7:    seg = 7'b1111000;
            4'd8:    seg = 7'b0000000;
            4'd9:    seg = 7'b0010000;
            default: seg = 7'b1111111;
        endcase
    end

endmodule
```

파일명: `tb_fnd_multiplexer_4digit.v`


**Step 2-4 · Basys3 4자리 FND 카운터 종합**

```text
100MHz Clock → 0.05초 Tick → 0.1초 Tick → 4자리 BCD Counter
                                         → FND Scan + Multiplexing → seg, an
```

| 포트 | 역할 |
|---|---|
| `btnU` | Reset |
| `sw[0]` | Enable |
| `led[3:0]` / `led[7:4]` | digit0 / digit1 |
| `led[8]` / `led[9]` | `blink_10hz` / `blink_5hz` |
| `seg`, `an`, `dp` | FND (DP는 끔) |

파일명: `basys3_step2_4digit_fnd_counter.v`

```verilog
module basys3_step2_4digit_fnd_counter(
    input             clk,    // Basys3 100MHz Clock
    input             btnU,   // Reset 버튼
    input      [15:0] sw,     // sw[0]: Counter Enable
    output     [15:0] led,    // 상태 확인 LED
    output reg [6:0]  seg,    // Segment 출력, Active-Low
    output reg [3:0]  an,     // Digit 선택 출력, Active-Low
    output            dp      // Decimal Point, Active-Low
);

    reg [22:0] div_count;     // 0.05초 Tick 생성 Counter
    reg        half_count;    // 0.05초 Tick 2회 확인용
    reg        tick_0p05s;    // 0.05초마다 1 Clock 동안 1
    reg        tick_0p1s;     // 0.1초마다 1 Clock 동안 1
    reg        blink_10hz;    // 0.05초마다 반전
    reg        blink_5hz;     // 0.1초마다 반전

    reg [15:0] scan_div;      // FND Scan 속도 생성 Counter
    reg  [1:0] digit_sel;     // 현재 선택 Digit

    reg  [3:0] digit0;        // 1의 자리
    reg  [3:0] digit1;        // 10의 자리
    reg  [3:0] digit2;        // 100의 자리
    reg  [3:0] digit3;        // 1000의 자리
    reg  [3:0] current_digit; // 현재 표시할 Digit 값

    assign dp         = 1'b1;        // Decimal Point 끔
    assign led[3:0]   = digit0;
    assign led[7:4]   = digit1;
    assign led[8]     = blink_10hz;
    assign led[9]     = blink_5hz;
    assign led[15:10] = 6'd0;

    // 0.05초 / 0.1초 Tick과 Blink 생성
    always @(posedge clk) begin
        if (btnU) begin
            div_count  <= 23'd0;
            half_count <= 1'b0;
            tick_0p05s <= 1'b0;
            tick_0p1s  <= 1'b0;
            blink_10hz <= 1'b0;
            blink_5hz  <= 1'b0;
        end
        else begin
            tick_0p05s <= 1'b0;
            tick_0p1s  <= 1'b0;

            if (div_count == 23'd4_999_999) begin
                div_count  <= 23'd0;
                tick_0p05s <= 1'b1;
                blink_10hz <= ~blink_10hz;

                if (half_count == 1'b1) begin
                    half_count <= 1'b0;
                    tick_0p1s  <= 1'b1;
                    blink_5hz  <= ~blink_5hz;
                end
                else begin
                    half_count <= 1'b1;
                end
            end
            else begin
                div_count <= div_count + 1'b1;
            end
        end
    end

    // 4자리 BCD Counter
    always @(posedge clk) begin
        if (btnU) begin
            digit0 <= 4'd0;
            digit1 <= 4'd0;
            digit2 <= 4'd0;
            digit3 <= 4'd0;
        end
        else begin
            if (sw[0] && tick_0p1s) begin
                if (digit0 == 4'd9) begin
                    digit0 <= 4'd0;
                    if (digit1 == 4'd9) begin
                        digit1 <= 4'd0;
                        if (digit2 == 4'd9) begin
                            digit2 <= 4'd0;
                            if (digit3 == 4'd9)
                                digit3 <= 4'd0;
                            else
                                digit3 <= digit3 + 1'b1;
                        end
                        else begin
                            digit2 <= digit2 + 1'b1;
                        end
                    end
                    else begin
                        digit1 <= digit1 + 1'b1;
                    end
                end
                else begin
                    digit0 <= digit0 + 1'b1;
                end
            end
        end
    end

    // FND Scan: 상위 2비트로 4자리 순차 선택
    always @(posedge clk) begin
        if (btnU) begin
            scan_div  <= 16'd0;
            digit_sel <= 2'd0;
        end
        else begin
            scan_div  <= scan_div + 1'b1;
            digit_sel <= scan_div[15:14];
        end
    end

    // 자리 선택
    always @(*) begin
        case (digit_sel)
            2'd0: begin current_digit = digit0; an = 4'b1110; end
            2'd1: begin current_digit = digit1; an = 4'b1101; end
            2'd2: begin current_digit = digit2; an = 4'b1011; end
            2'd3: begin current_digit = digit3; an = 4'b0111; end
            default: begin current_digit = 4'd0; an = 4'b1111; end
        endcase
    end

    // 세그먼트 디코더
    always @(*) begin
        case (current_digit)
            4'd0:    seg = 7'b1000000;
            4'd1:    seg = 7'b1111001;
            4'd2:    seg = 7'b0100100;
            4'd3:    seg = 7'b0110000;
            4'd4:    seg = 7'b0011001;
            4'd5:    seg = 7'b0010010;
            4'd6:    seg = 7'b0000010;
            4'd7:    seg = 7'b1111000;
            4'd8:    seg = 7'b0000000;
            4'd9:    seg = 7'b0010000;
            default: seg = 7'b1111111;
        endcase
    end

endmodule
```

`scan_div[15:14]`는 65,536클록(약 0.66ms)마다 한 바퀴 돌므로 자리마다 약 0.16ms씩 켜져, 눈에는 네 자리가 동시에 켜진 것으로 보입니다.

| 조건 | 확인 내용 |
|---|---|
| `sw[0] = 1` | 4자리 값이 0.1초마다 증가 |
| `sw[0] = 0` | 정지 |
| `btnU` | 0000으로 초기화 |
| `led[8]`, `led[9]` | 10Hz·5Hz 점멸 |
| `an[3:0]` | 빠르게 순환 |

## 정리와 점검

| 개념 | 핵심 |
|---|---|
| 래치 | Enable 동안 열려 있는 저장소, FPGA에서는 피함 |
| 플립플롭 | 클록 에지 순간에만 저장, RTL의 기본 저장소 |
| `=` / `<=` | 조합 / 순차 대입 |
| 레지스터 | 여러 비트 동시 저장 (Enable·Load·Reset) |
| 시프트 레지스터 | 저장 + 이동, SIPO·PISO는 UART의 기초 |
| Tick | 1클록 폭 **Enable**, 클록이 아님 |
| Blink | Duty 50% 점멸, 눈으로 확인용 |
| FND 스캔 | 카운터와 별도로 빠르게 자리 순환 |
